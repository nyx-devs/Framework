# Positive + Bad merits (Roblox)

Replace these scripts in Studio:

| File | Place as |
|------|----------|
| `MeritService.lua` | ServerScriptService/Ro-School/**MeritService** (ModuleScript) |
| `MeritServer.server.lua` | ServerScriptService/Ro-School/**MeritServer** (Script) |
| `MeritStaffClient.client.lua` | StarterPlayerScripts/**MeritStaffClient** (LocalScript) |

## In game
1. Click **Merits** (or press M)
2. Choose **Positive (+)** or **Bad (−)**
3. Student username, amount, reason → **Award**

Positive → +amount on website  
Bad → −amount + merit_kind = bad  

## Config
Set ApiBaseUrl, MeritApiKey, StaffGroupId in **Config**.
